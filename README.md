# Robot Button

Jogo idle/clicker de robôs para o Poki, em JavaScript puro + canvas, com pixel art desenhada por código.

- **Botão vermelho:** toque para ganhar moedas. Até 5 robôs no **time** apertam o botão sozinhos.
- **Grade (30 vagas):** crie robôs e arraste um em cima de outro igual para juntar e formar um robô melhor (30 níveis).
  No celular, tocar num robô junta com um igual ou manda para o time.
- **Abas:** Upgrades (com o Renascimento), Batalha (9 hordas de monstros, até 10 robôs), Compêndio (cada robô ou
  monstro novo dá pontos de habilidade e moedas) e Opções.
- **Renascimento:** perde moedas, robôs e upgrades e ganha pontos de habilidade. Os pontos só são gastos na
  árvore de habilidades na hora de renascer.
- 15 idiomas; funciona deitado e com o celular em pé.

Rodar: abra o `index.html` por um servidor local (ex.: `npx serve`).
Versão para o Poki: `npm install` (uma vez) e `npm run construir` → pasta `dist/` (é o que vai no zip).
